# Design Lead

## Accountable for

- user flow and interface quality;
- shared visual decisions;
- communicating designs before implementation;
- loading, empty, success, error and permission states;
- basic accessibility and consistency reviews.

## Current deliverables

- [ ] Login/account wireframe.
- [ ] Registered-user-directory wireframe.
- [ ] One-to-one chat wireframe.
- [ ] Navigation flow between those screens.
- [ ] Colour, typography and spacing choices.
- [ ] Loading, empty, error and retry presentations.
- [ ] Camera-permission and upload-error states for the later photo stage.

## Review each UI pull request

- [ ] It follows the agreed flow.
- [ ] Text is understandable without developer knowledge.
- [ ] Tap targets and text are comfortably readable.
- [ ] Colours have usable contrast.
- [ ] Empty and error behaviour is specified.
- [ ] Reusable components look consistent.
- [ ] The implementation matches the linked wireframe or explains the change.

Design changes that affect existing implementation must become an issue or a comment on the relevant issue; do not change expectations silently.
